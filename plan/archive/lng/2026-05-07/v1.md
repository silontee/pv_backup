## 3. 시나리오 생성

### 3.1 포트폴리오 합산

8 사이트 분포 → 1개 포트폴리오 분포:

```
PV_total(t) = Σᵢ PV_i(t)
   - 평균: μ_total = Σ μ_i × capacity_i
   - 분산: σ²_total = depends on correlation
```

**합산 방식 결정 — 사이트 간 correlation 측정 후**:

```python
# NGBoost 학습 후 사이트 간 *잔차* correlation 측정
residuals = actual - predicted   # 사이트별
cor_matrix = residuals.pivot(...).corr()
mean_cor = cor_matrix.mean()
```

선택 기준:
- mean_cor > 0.7 → **완전상관 가정** (σ_total = Σ σ_i, 보수적)
- 0.3 < mean_cor < 0.7 → **cor matrix 기반** σ_total = √(σᵀ Σ σ)
- mean_cor < 0.3 → **독립 가정** (σ²_total = Σ σ²_i)

PoC 권장: **완전상관 보수적 시작** → 결과 보고 정밀화.

### 3.2 시나리오 도출 — Quantile + Monte Carlo 둘 다

**Quantile 5개** (운영자 직관):
```
worst       = q05    "5% 확률로 이보다 적게"
pessimistic = q25
expected    = q50
optimistic  = q75
best        = q95
```

**Monte Carlo 1000 샘플** (통계적):
```python
# 시간별 독립 샘플링 (시간 간 correlation은 모델이 이미 잡음)
samples = np.random.normal(mu, sigma, size=(1000, 24))
samples = np.clip(samples, 0, capacity_max)
```

**왜 둘 다?**:
- Quantile: 대시보드 시각화, 운영자 빠른 판단
- Monte Carlo: 시나리오 re-weighting 풍부도, 정량 통계

## 4. 실시간 운영 — Gap 기반 LNG 결정

### 4.1 Gap 정의

```
시점 t:
  predicted_pv(t) = D-1 시점 시나리오 풀의 median
  actual_pv(t)    = KOEN 실측 (시뮬레이션)
  gap(t) = actual_pv(t) - predicted_pv(t)
```

| Gap | 의미 | LNG 조치 |
|---|---|---|
| -X (음수, 큼) | PV 부족 | **LNG 출력 +X 증가** (ramp up) |
| 작음 | 예측 거의 맞음 | 기존 계획 유지 |
| +X (양수, 큼) | PV 초과 | **LNG 출력 -X 감소** (ramp down, 연료비 절감) |

### 4.2 Re-weighting으로 *미래 gap propagate*

현재 gap만 보는 건 myopic. *시나리오 re-weighting*으로 미래 시간까지 영향 확장:

```python
# t시점 PV 실측 들어옴
pv_actual_t = ...
weights = compute_likelihood(pool, pv_actual_t, t)   # trajectory[t] ≈ pv_actual_t인 시나리오 weight ↑
pool_reweighted = (weights * pool) / weights.sum()

# 후속 시간 분포 추출
future_dist = pool_reweighted[t+1:t+24]   # 갱신된 미래 분포
lng_plan_future = compute_lng(future_dist)   # 더 정확한 LNG 계획
```

→ "12시 예측보다 낮음 → 13시·14시도 낮을 가능성" 자동 반영.

### 4.4 PoC 의사결정 단순화

복잡한 Stochastic Unit Commitment (SUC) 대신:

```
[단순 deterministic per scenario]
Each scenario s:
  LNG_required(s, t) = max(0, demand(t) - PV(s, t) - 석탄_고정 - 기타)
  ramp_check(s, t) = LNG_required(s, t) - LNG_required(s, t-1) ≤ ramp_max

[5 quantile 시나리오 모두 표시 → 운영자가 보고 결정]
[Monte Carlo: 1000 시나리오의 95% percentile = 보수적 LNG 계획]
```
