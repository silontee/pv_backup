# Plan v6: 태양광 변동성 대비 LNG 백업 최적화 플랫폼

## 프로젝트 범위

### 예측 대상
- **태양광 자체설비 98.2MW** (15개 사이트, 23개 호기)
- SPC 512.8MW는 데이터 확보 시 확장 (남동발전 답변 대기)

### 백업 수단
- **분당 LNG 920MW** (가스터빈 CG1~8 + 증기터빈 CS1~2)
- 남동발전에서 유일하게 출력 조절이 가능한 자원 (48~100%, 기동 1~4시간)

### 제외
- 석탄 (영흥/삼천포/여수): 최소출력 고정, 현 태양광 규모에서 조절 불가
- 영동 바이오매스: 석탄과 유사
- 연료전지: LNG를 쓰지만 일정 출력으로 운전, 조절 불가
- 소수력: 화력 배수로 활용, 용량 미미 (18MW)
- 풍력: 변동성 추가 자원이지 백업이 아님 (향후 예측 대상 확장 가능)

## 시스템 구조

```
Layer 1: 태양광 예측 엔진
  입력: 기상 데이터 (과거 학습 + 실시간 업데이트)
  출력: 시간별 발전량 예측 + 불확실성 구간 (확률분포)
  목표: 월평균 오차 4% 이하 (NMAE 기준)

Layer 2: LNG 제약 모델  
  입력: 분당 LNG 과거 운전 이력
  출력: 호기별 물리적 제약 파라미터
        (기동시간, 최소운전시간, 최소출력, 램프율)
  목표: "CG1이 지금 꺼져있으면 언제부터 몇 MW 가능한지"

Layer 3: 백업 스케줄 추천
  입력: Layer 1 예측 + Layer 2 제약
  출력: LNG 호기별 대기/기동 추천 + 리스크 분석
  목표: 불확실성 구간에 맞춘 의사결정 타이밍 제시
```

## 운영 플로우

### D-1일 (하루전 계획)

```
09:00  기상 예보 수신 (D일 24시간)
       ↓
       태양광 예측 모델 실행
       → "내일 13시 태양광 300MW 예측"
       → "불확실성: 10%ile=200MW, 90%ile=380MW"
       ↓
       LNG 백업 계획 수립
       → "최악 시 100MW 부족 가능"
       → "CG1 대기 권장 (기동 준비 1시간)"
       ↓
10:00  KPX 가용용량 신고 (운영자 확인 후)
       ↓
17:00  기상 예보 업데이트 → 예측 보정 → 2차 신고
```

### D일 (실시간 운영)

```
매 시간: 실시간 기상 수신 → 예측 업데이트
         ↓
         불확실성 재계산 (시간이 갈수록 줄어듦)
         ↓
         LNG 계획 수정
         
예시 타임라인:
  07:00  "오늘 구름 많음, 13시 예측 250MW로 하향"
         → "CG1 11시 기동 권장"
  11:00  "구름 빠지는 중, 13시 예측 280MW로 상향"  
         → "CG1 기동 보류, 대기 유지"
  13:00  실측 270MW → 예측 범위 내 → OK
```

### 핵심 원리: 불확실성의 시간별 축소

```
D-1일 예보:    ±50MW  (넓음 → 보수적 대비)
D일 6시간전:   ±30MW
D일 3시간전:   ±15MW  (좁음 → 정밀 대응)
D일 실시간:    ±5MW   (거의 확정)
```

이 축소 과정을 정량화하여 "언제 기동 결정을 내려야 하는지"를 제시하는 것이 핵심


기상 변수 전략 (DTTrans 논문 참고):
- **GHI 없이도 PV 예측 가능** (운량/기온/풍속/습도 4개 변수)
- ASOS 중 GHI 관측소가 22개뿐이므로 GHI에 의존하지 않는 접근이 현실적
- 1시간 해상도 기준 관측소-사이트 거리 50km 이내면 OK (전부 충족)
