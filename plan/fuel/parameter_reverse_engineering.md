# 화력(분당 LNG) 운전 파라미터 역추정 방법론

> **배경**: 남동발전 측 답변(2026-04-21)에 따라 호기별 최소출력·램프율·기동시간·기동비용 등의 운전 파라미터는 **영업비밀/국가보안 이슈로 제공 불가**. 따라서 공공데이터 포털에 공개된 **분당 LNG 시간별 발전실적 시계열**에서 역추정한다. 이는 `plan/main/problem_definition.md §0`에 정의된 제약의 직접 결과.

## 대상 자원

- **분당 LNG 920 MW**, CG1~CG8 (가스터빈) + CS1~CS2 (증기터빈)
- 데이터: `data/thermal_hourly/` 2022-01 ~ 2025-12 (48개월, 10 호기별 시간별 발전량)
- 남동발전에서 출력 조절 가능한 **유일한** 자원 → 변동성 백업의 핵심

## 역추정 대상 파라미터

| # | 파라미터 | 단위 | 업계 추정치 (LNG CC) | 역추정 근거 |
|---|---------|------|------------------|------------|
| 1 | **Pmin (최소출력)** | MW | ~48% × Pmax | 가동 중 히스토그램의 하한 |
| 2 | **Pmax (최대출력)** | MW | 명판 기준 | 상한 분위수 |
| 3 | **램프율(ramp rate)** | MW/분 | ~30 MW/분 | 연속 시간대의 ΔP/Δt 분포 |
| 4 | **최소 기동 시간 (min up time)** | 시간 | ~4시간 | 연속 가동 런 길이 분포 |
| 5 | **최소 정지 시간 (min down time)** | 시간 | ~2시간 | 연속 정지 런 길이 분포 |
| 6 | **Cold start 시간** | 시간 | ~6시간 | 정지 후 재가동 시 P 상승 곡선 |
| 7 | **기동 비용** | 원/회 | ~5천만원 (업계 추정) | 직접 역추정 불가. 문헌 값 사용 |
| 8 | **변동비** | 원/kWh | ~160 | SMP/연료비 공공데이터 교차 |

## 데이터 기반 추정 기법

### 1) On/Off 상태 라벨링
- 시간별 발전량 `gen_kwh` 시계열에서 임계값(예: 10 MW) 이하면 **정지**, 초과면 **가동** 라벨
- 호기별로 히스토그램 그려서 이중모드(bimodal) 확인 → 임계값 자동 결정

### 2) Pmin 추정
- "가동 중" 상태의 발전량 분포 하한(1~5 percentile) → 물리적 최소출력
- 이론값(Pmax × 48%)과 비교하여 검증

### 3) 램프율 추정
- 연속 가동 시간대의 `ΔP = P(t+1) - P(t)` 분포
- 99 percentile → **단위 시간(1시간) 내 가능 최대 출력 변화**
- 단위 환산: `MW/h → MW/분` (÷60)
- 업계 추정 ~30 MW/분과 비교

### 4) 기동/정지 시간
- 상태 변화 이벤트 추출: 정지→가동 (시작) 혹은 가동→정지 (종료)
- **정지 지속 시간 분포**의 하한 → 최소 정지 시간
- **가동 지속 시간 분포**의 하한 → 최소 기동 시간

### 5) Cold start 곡선
- "장시간 정지 후 재가동" 사례 추출 (정지 > 12h 기준)
- 재가동 후 H시간 동안 P(t) 추적 → 평균 상승 곡선
- 곡선이 Pmax에 도달하는 시간 = cold start duration

### 6) 변동비 교차 검증
- 월별 분당 LNG 가동 패턴 × SMP 가격 비교
- 가동 시 SMP가 LNG 변동비 근처 → 급전 merit order 추정 가능
- 공공데이터: KPX SMP 공시, 연료비 가격 공시

## 베이지안 일관성
- 각 파라미터는 **점 추정 + 사후분포**로 제공
- 업계 추정치를 사전분포로 쓰고 데이터로 업데이트 (Bayesian shrinkage)
- 하류 Stochastic UC에서 이 파라미터 불확실성도 반영 가능

## 검증 방법
1. 추정 파라미터로 **합성 가동 시뮬레이션** → 실측 패턴과 비교 (reconstruction error)
2. 공공 문헌값(LNG CCGT 표준) 대비 합리적 범위 내 포함 여부
3. 남동발전 답변 후속 검증 기회가 있으면 사후 확인 요청
