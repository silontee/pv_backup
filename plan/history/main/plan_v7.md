# Plan v7: 태양광 변동성 대비 LNG 백업 최적화 플랫폼

> **데이터 개요(소스, 기간, 호기 구성, 좌표 매핑, 수집 현황)는 `plan/main/data_strategy.md`가 SSoT.**
> 이 문서에서는 데이터 요약만 기술하고, 세부는 모두 data_strategy.md를 참조한다.

## 과제 성격 (2026-04-21 남동발전 회신 반영)

- **PoC + 대시보드 프로토타입**. 실제 운영 시스템 수준 아님. (KOEN AX전략부 회신 §6)
- **SPC 513MW 및 화력 운전 파라미터 제공 불가** → 학습 12 호기 + 화력은 공공 발전실적에서 **역추정**.
- VGEN/VPP와 독립. 예측 + 화력 최적화 + 의사결정 지원 전체를 **처음부터 구축**.
- 경진대회 성격상 **방법론의 창의성·다양성 가점** → Bayesian 1층 + FiLM 2층 + 시나리오 기반 아키텍처가 차별화 포인트.
- 전국 신재생 확장은 본 PoC 범위 밖. 최종 기획서/제안서에서 언급.
- 상세: `plan/main/problem_definition.md` §0

## 프로젝트 범위

### 예측 대상
- **태양광 자체설비 — 현재 사용 가능 12 호기** (2024년 실데이터 피크 시각 기반 판정)
  - 전체 20 호기 중 ESS 방전 왜곡으로 사용 불가 8 호기 제외 → 상세는 `plan/main/data_strategy.md` §2
  - 고흥만 수상 63.5MW가 포트폴리오의 65%+
- 여수, 탑선은 시간별 데이터 없음(일합계만) → 제외
- SPC 512.8MW는 데이터 확보 시 확장 (남동발전 답변 대기)

### 백업 수단
- **분당 LNG 920MW** (가스터빈 CG1~8 + 증기터빈 CS1~2)
- 남동발전에서 유일하게 출력 조절이 가능한 자원 (48~100%, 기동 1~4시간)

### 제외
- 석탄 (영흥/삼천포/여수): 최소출력 고정, 현 태양광 규모에서 조절 불가
- 영동 바이오매스: 석탄과 유사
- 연료전지: LNG를 쓰지만 일정 출력으로 운전, 조절 불가
- 소수력: 화력 배수로 활용, 용량 미미 (18MW)
- 풍력: 변동성 추가 자원이지 백업이 아님 (향후 예측 대상 확장 가능)

## 시스템 구조

```
Layer 1: 태양광 예측 엔진
  입력: GHI + 기온 + 습도 + 풍속
  출력: 시간별 발전량 예측 + 불확실성 구간 (확률분포)
  목표: 월평균 오차 4% 이하 (NMAE 기준)

Layer 2: LNG 제약 모델  
  입력: 분당 LNG 과거 운전 이력
  출력: 호기별 물리적 제약 파라미터
        (기동시간, 최소운전시간, 최소출력, 램프율)
  목표: "CG1이 지금 꺼져있으면 언제부터 몇 MW 가능한지"

Layer 3: 백업 스케줄 추천
  입력: Layer 1 예측 + Layer 2 제약
  출력: LNG 호기별 대기/기동 추천 + 리스크 분석
  목표: 불확실성 구간에 맞춘 의사결정 타이밍 제시
```

## 데이터 전략

> 상세는 `plan/main/data_strategy.md` (SSoT). 여기는 요지만.


### 핵심 원칙

1. **학습 데이터는 실측**을 사용한다
2. **예보 데이터는 예보 소스**를 사용한다
3. 변수별로 **가장 적합한 소스**를 선택한다 (단일 소스 강제 아님)
4. GHI는 구름 영향이 이미 반영된 값이므로 **운량 변수는 별도 수집하지 않는다**

### 변수별 소스 확정

| 변수 | 학습용 (실측) | 예보용 (D-1) | 선택 근거 |
|------|-------------|-------------|----------|
| **GHI (일사량)** | **GK-2A 위성 NC (2km)** | **Open-Meteo API** | ASOS는 거리 문제 + 4개소 미관측. GK-2A는 2km 실측, R=0.984 |
| **기온** | **ASOS 11개 관측소** | **단기예보 API** | 20~30km 거리에서도 상관 0.85+. 공간 변동 작음 |
| **습도** | **ASOS 11개 관측소** | **단기예보 API** | 기온과 유사한 공간 특성 |
| **풍속** | **ASOS 11개 관측소** | **단기예보 API** | 50km+에서도 상관 유지. 가장 거리 영향 적음 |
| **운량** | 수집 안 함 | 수집 안 함 | GHI가 구름 영향 포함. 별도 불필요 |

### 학습-예보 소스 불일치 해결

```
학습: GK-2A GHI (위성 실측, W/m²)
예보: Open-Meteo GHI (NWP 예보, W/m²)
→ 소스는 다르지만 단위와 물리적 의미 동일
→ NWP 예보에는 편향(bias)이 있을 수 있음
→ MOS(Model Output Statistics) 보정으로 해결 가능
→ Open-Meteo 과거 아카이브로 편향 보정 모델 학습 가능
```

### GHI 소스 선정 과정

```
ASOS 일사량 → 11개소 중 4개소 미관측 + 거리 20~30km
  → 운량 상관 0.5~0.75 (broken cloud)
  → 기온도 해안가 겨울에 상관 0.52까지 하락
  → 부적합

발전소 기상 → 삼천포/영흥/영동/여수/분당 5개소
  → GHI/운량 미관측 (일조시간도 거의 없음)
  → 기온/습도/풍속만 있음, 일별 데이터
  → GHI용으로 부적합

GK-2A 위성 → 2km 해상도, 한반도 전역
  → 1dCNN AI 기반 일사량 산출 (ASOS 대비 R=0.984, RMSE 48.6 W/m²)
  → PV 사이트 바로 위 2km 격자에서 추출 가능
  → 2020-01 ~ 2024-12 제공
  → 학습용 최적

Open-Meteo → ECMWF/GFS 기반 예보
  → 좌표 입력 시 GHI(W/m²) 직접 반환
  → 무료, API 키 불필요
  → 과거 아카이브도 제공
  → 예보용 최적
```

## GK-2A NC 파일 구조

```
변수: DSR (Downward Shortwave Radiation) = GHI
단위: W/m²
격자: 900 × 900 픽셀 (LCC 투영, 2km)
시간: 10분 단위 → 매 정시(00분)만 수집 = 1시간 단위
영역: 한반도 (KO)
API: https://apihub.kma.go.kr/api/typ05/api/GK2A/LE2/SWRAD/KO/data?date={yyyymmddHHMM}&authKey={key}
시간 변환: KST 06~20시 = UTC 전날21시~당일11시
검증: ASOS 42개 지점 대비 MBE=1.909 W/m², RMSE=48.611 W/m², R=0.984
```

## 예보 데이터 구조

### Open-Meteo (GHI 예보)

```
API: https://api.open-meteo.com/v1/forecast
파라미터: latitude, longitude, hourly=shortwave_radiation,direct_radiation,diffuse_radiation
모델: 기본(best_match) — ECMWF/GFS 자동 선택
해상도: ~9~25km (모델별)
시간: 1시간
예보 범위: +7일 (168시간)
비용: 비상업 무료
과거: archive-api.open-meteo.com (2022년~)
테스트 결과: 고흥만 2024-07-01 12시 GHI = 702 W/m² (정상)
```

### 기상청 단기예보 (기온/습도/풍속 예보)

```
API: https://apihub.kma.go.kr/api/typ01/cgi-bin/url/nph-dfs_shrt_grd
변수: TMP(기온), REH(습도), WSD(풍속), SKY(하늘상태), POP(강수유무), PCP(강수량)
발표: 3시간 간격 (02,05,08,11,14,17,20,23시)
예보: 1시간 간격, 최대 +72시간
좌표: 동네예보 격자 (약 5km)
참고: GHI 없음 (SKY 3단계만: 맑음/구름많음/흐림)
좌표 변환: https://apihub.kma.go.kr/api/typ01/cgi-bin/url/nph-dfs_xy_lonlat?lon={경도}&lat={위도}
```
