# Plan v6: 태양광 변동성 대비 LNG 백업 최적화 플랫폼

## 프로젝트 범위

### 예측 대상
- **태양광 자체설비 98MW** (22개 사이트, 시간별)
- SPC 513MW는 데이터 확보 시 확장 (남동발전 답변 대기)

### 백업 수단
- **분당 LNG 920MW** (가스터빈 CG1~8 + 증기터빈 CS1~2)
- 유일하게 출력 조절이 가능한 자원 (48~100%, 기동 1~4시간)

### 제외
- 석탄 (영흥/삼천포/여수): 최소출력 고정, 현 규모에서 조절 불가
- 영동 바이오매스: 석탄과 유사
- 연료전지: 일정 출력, 조절 불가
- 소수력: 용량 미미 (18MW)
- 풍력: 변동성 추가 자원이지 백업이 아님 (향후 예측 대상 확장 가능)

---

## 시스템 구조

```
Layer 1: 태양광 예측 엔진
  입력: 기상 데이터 (과거 학습 + 실시간 업데이트)
  출력: 시간별 발전량 예측 + 불확실성 구간 (확률분포)
  목표: 월평균 오차 4% 이하 (NMAE 기준)

Layer 2: LNG 제약 모델  
  입력: 분당 LNG 과거 운전 이력
  출력: 호기별 물리적 제약 파라미터
        (기동시간, 최소운전시간, 최소출력, 램프율)
  목표: "CG1이 지금 꺼져있으면 언제부터 몇 MW 가능한지"

Layer 3: 백업 스케줄 추천
  입력: Layer 1 예측 + Layer 2 제약
  출력: LNG 호기별 대기/기동 추천 + 리스크 분석
  목표: 불확실성 구간에 맞춘 의사결정 타이밍 제시
```

## 운영 플로우

### D-1일 (하루전 계획)

```
09:00  기상 예보 수신 (D일 24시간)
       ↓
       태양광 예측 모델 실행
       → "내일 13시 태양광 300MW 예측"
       → "불확실성: 10%ile=200MW, 90%ile=380MW"
       ↓
       LNG 백업 계획 수립
       → "최악 시 100MW 부족 가능"
       → "CG1 대기 권장 (기동 준비 1시간)"
       ↓
10:00  KPX 가용용량 신고 (운영자 확인 후)
       ↓
17:00  기상 예보 업데이트 → 예측 보정 → 2차 신고
```

### D일 (실시간 운영)

```
매 시간: 실시간 기상 수신 → 예측 업데이트
         ↓
         불확실성 재계산 (시간이 갈수록 줄어듦)
         ↓
         LNG 계획 수정
         
예시 타임라인:
  07:00  "오늘 구름 많음, 13시 예측 250MW로 하향"
         → "CG1 11시 기동 권장"
  11:00  "구름 빠지는 중, 13시 예측 280MW로 상향"  
         → "CG1 기동 보류, 대기 유지"
  13:00  실측 270MW → 예측 범위 내 → OK
```

### 핵심 원리: 불확실성의 시간별 축소

```
D-1일 예보:    ±50MW  (넓음 → 보수적 대비)
D일 6시간전:   ±30MW
D일 3시간전:   ±15MW  (좁음 → 정밀 대응)
D일 실시간:    ±5MW   (거의 확정)
```

이 축소 과정을 정량화하여 "언제 기동 결정을 내려야 하는지"를 제시하는 것이 핵심

## 데이터 요구사항

### 태양광 발전 데이터

| 항목 | 소스 | 상태 | 비고 |
|------|------|------|------|
| 자체설비 98MW 시간별 | 홈페이지 다운로드 | 재수집 필요 | 크롤링 데이터 불량 (대부분 0) |
| SPC 513MW 시간별 | 남동발전 요청 | 답변 대기 | 확보 시 확장 |

### LNG 발전 데이터

| 항목 | 소스 | 상태 | 비고 |
|------|------|------|------|
| 분당 CG1~8, CS1~2 시간별 | 홈페이지 다운로드 | 품질 확인 필요 | 크롤링 데이터 있음 |
| 기동/정지 패턴 | 위 데이터에서 추출 | 미수행 | 0→양수 전환 패턴 분석 |

### 기상 데이터

| 용도 | 필요 변수 | 소스 | 상태 |
|------|----------|------|------|
| **학습용 (과거)** | GHI(일사량), 운량, 기온, 습도, 풍속 | 별도 확보 예정 | 님이 제공 |
| **D-1 예보** | 위와 동일 (예보값) | Open-Meteo / LDAPS | 확보 가능 |
| **D일 실시간** | 위와 동일 (관측값) | ASOS / 남동발전 기상API | 확보 가능 |

#### 기상 변수 우선순위

| 변수 | 중요도 | 이유 |
|------|--------|------|
| GHI (전천일사량) | ★★★ | 발전량의 직접 원인 |
| 운량 | ★★★ | GHI 없으면 이걸로 추정, 변동성 주범 |
| 기온 | ★★ | 고온 → 패널 효율 저하 |
| 습도 | ★ | 대기 투과율 |
| 풍속 | ★ | 패널 냉각 |

| 전력거래 입찰 정보 | CSV (2024년) | 확보 완료 | SMP 결정 패턴 분석 |

### 화력 전체 (시뮬레이션용)

## 개발 단계

### Phase 0: 데이터 확보 및 검증
- [ ] 태양광 시간별 데이터 재수집 (홈페이지 다운로드)
- [ ] 분당 LNG 크롤링 데이터 품질 검증
- [ ] 기상 데이터 확보 (학습용 과거)
- [ ] 기상 예보/실시간 소스 확정 및 연동

### Phase 1: EDA 및 베이스라인
- [ ] 태양광 발전 패턴 분석 (시간대별, 계절별, 사이트별)
- [ ] 분당 LNG 운전 패턴 분석 (기동/정지 빈도, 출력 변화)
- [ ] 태양광-기상 상관관계 분석
- [ ] 베이스라인 예측 (persistence, 통계 모델)

### Phase 2: 예측 모델
- [ ] 태양광 예측 모델 (기상 입력 → 발전량 + 불확실성)
- [ ] 시간대별 오차 분석 (어떤 시간이 가장 위험한지)
- [ ] 실시간 업데이트 로직 (예보 → 실시간 전환 시 정확도 개선 검증)

### Phase 3: 백업 스케줄 엔진
- [ ] LNG 제약 모델 (기동시간, 최소운전, 램프율)
- [ ] 불확실성 기반 기동 의사결정 로직
- [ ] 시나리오 시뮬레이터 (최악/최선/기본)
- [ ] 비용 분석 (불필요 기동 vs 미대비 리스크)

### Phase 4: 통합 및 시연
- [ ] D-1 → D일 운영 플로우 구현
- [ ] 대시보드 (예측 + 불확실성 + LNG 추천)
- [ ] PBP 시나리오 시뮬레이션 (이중정산 시 절감 효과)
- [ ] 8GW 확장 시뮬레이션 (석탄 포함)
