# 데이터 전략 (Data Strategy)

> **이 문서는 이 프로젝트 데이터 개요의 단일 소스(SSoT)이다.**
> 데이터 소스/기간/호기 구성/좌표 매핑/제외 정책이 바뀌면 **무조건 이 문서를 먼저 갱신**한다.
> 다른 plan 문서(`plan_v*.md`, `pv/`, `fuel/`, `esg/`)는 데이터 개요를 중복 기술하지 않고 이 문서를 참조한다.

## 2. 태양광 호기 확정 리스트 (2026-04-20 기준)

### 원자료 (solar_hourly CSV)

- 15 사이트 × 22 호기 로우 존재
- **여수태양광, 탑선태양광**은 시간별 값이 비어 있고 일합계만 제공 → **제외** (2 호기)
- 시간별 데이터 존재: 13 사이트 × 20 호기

### 판정 기준 (데이터 기반)

2024년 전체 기간 호기별 시간대 평균 발전량을 계산하여 **피크 시각**을 판정 기준으로 사용한다.

- **사용 가능**: 피크 시각 ≤ 15시 (정상 태양광 패턴, 13~14시 피크)
- **사용 불가**: 피크 시각 ≥ 16시 (ESS 방전이 합산되어 PV 순발전량으로 해석 불가)

수동 ESS dict가 아니라 **실데이터 피크 시각**을 진정한 판정 기준으로 삼는 이유:
수동 dict는 외부 공시자료 기반이라 누락/오류 가능(실제로 영흥태양광 #2는 수동 dict에서 ESS로 표기됐지만 실데이터 피크는 13시 → 순 태양광으로 확정). 데이터가 진실이다.

## 4. 변수별 소스 선택 근거

### GHI: GK-2A 위성 (학습) + Open-Meteo (예보)

- ASOS GHI: 11개소 중 4개소가 미관측, 거리 20~30km → 부적합
- GK-2A: 2km 해상도, PV 사이트 바로 위 실측, ASOS 대비 R=0.984, RMSE 48.6 W/m² → 학습용 최적
- Open-Meteo: ECMWF/GFS 기반 예보, 좌표 입력 시 GHI 직접 반환 → 예보용 최적

### 기온/습도/풍속: ASOS (학습) + 단기예보 (예보)

- 20~30km 거리에서도 상관 0.85+ (풍속은 0.9+)
- 공간 변동이 작아 ASOS로 충분
- 고흥만(수상)도 ASOS 고흥(5.3km)으로 커버 가능

### 운량: 수집 안 함

- GHI 자체가 구름 영향을 이미 반영한 값
- GHI = 직달(구름 없을 때) + 산란(구름에 의한 확산)
- GHI를 직접 사용하므로 운량 변수 불필요

### 학습-예보 소스 불일치 해결

```
학습: GK-2A GHI (위성 실측, W/m²)
예보: Open-Meteo GHI (NWP 예보, W/m²)
→ 단위 동일, NWP 편향은 MOS(Model Output Statistics)로 보정
→ Open-Meteo 과거 아카이브로 편향 보정 모델 학습 가능
```

11개 고유 좌표 (같은 발전소 내 사이트는 동일 좌표).

## 8. API 키 관리

### 공공데이터포털 (data.go.kr)
- 키: `.env` `DATA_GO_KR_API_KEY`
- 용도: 남동발전 API (태양광/화력/풍력/연료)

### 기상청 API허브 (apihub.kma.go.kr)
- 키: `.env` `KMA_APIHUB_KEYS` (9개, 쉼표 구분)
- 용도: GK-2A SWRAD NC, 단기예보, 초단기예보, 실황
- 제한: 키당 5GB/일

### Open-Meteo
- 키: 불필요 (무료)
